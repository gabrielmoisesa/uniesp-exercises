# POO — Aula 4: Visibilidade de Variáveis, String, Casting e Classe Math

Lista de exercícios práticos da disciplina de Programação Orientada a Objetos,
baseada nos conteúdos da Aula 4: escopo de variáveis, manipulação de String,
coerção implícita e explícita (casting), tipos float/double/byte e uso da
classe Math.

**Aluno:** Gabriel Moises Alves

## Estrutura

O projeto segue a organização pedida no enunciado: uma classe `Principal`,
contendo o método `main`, e uma classe `Questoes`, contendo um método para
cada exercício.

```
src/
├── Principal.java
└── Questoes.java
```

## Conteúdo praticado

- Escopo de variáveis e diferença entre declaração e inicialização
- Manipulação de String e uso de caracteres especiais (`\n`, `\t`, `\"`, `\\`)
- Coerção implícita e casting explícito entre tipos numéricos
- Diferenças entre `float`, `double` e `byte`, e perda de informação em
  conversões
- Métodos da classe `Math` (`abs`, `pow`, `sqrt`, `round`, `toRadians`,
  `toDegrees`)
- Geração de números aleatórios com `Math.random()`
- Entrada de dados com `Scanner`
